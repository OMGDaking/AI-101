# AI-101 vault — presentation path

Use this as a speaking map, not a script to read. The files show AI-assisted work; they do not stand in for Dakota's own review or learning.

## 1. Open with the through-line (20 seconds)

“I used AI to help make and organize study material, but I kept the judgment points visible: what to keep, what is uncertain, and what I still need to check myself.”

## 2. Show how context changed an image (1 minute)

Open the [Project 1 decision note](Project%201/decision-note.md) beside the [final poster](Project%201/artifacts/AI101_P1_Krug_Dakota_Poster.png). Point to the first and fourth images in `Project 1/Image Rounds/`. Explain one instruction that moved the work away from the first generic output. The context kit and AI-use log contain the evidence.

## 3. Show the study workflow (1 minute)

Open the [Project 2 workflow](Project%202/00-start-here.md) and [career-path guide](project-03/outputs/data-analyst-career-paths-rerun.md). The input can be an attachment, selected file, or pasted text. Codex drafts important notes, quiz questions, and practice questions; the human checks them against the source before relying on them.

## 4. Show the audit and agent boundary (1–2 minutes)

Open the [audit note](project-03/audit-note.md): pasted text worked by inference, so the input rule was made explicit and the same notes were rerun. Then open the [agent rules](project-03/vault-agent/hard-rules.md) and [run comparison](project-03/run-comparison.md). The proposed agent flags conflicting claims and missing data rather than guessing. The two comparison outputs are controlled same-session drafts, not independent agent sessions. See the [defense notes](project-03/defense-notes.md) for the short agent explanation.

## 5. End with a brief game demo (1 minute)

Open [Study Showdown](https://study-showdown-ai101.luckylemur33.chatgpt.site/). Show the menu, rules, a mode, and a point-value tile. Explain that the game turns material into editable four-choice cards; the right/wrong explanations and choices must be checked before play. Optional music is original and starts off.

## Honest close

“The agent files are connected and the game is live, but I still need to review the AI-drafted rules and guides in my own words and test the agent in a separate session. I will not claim those human steps are done.”

## Before presenting

- Open the vault and game ahead of time. Keep a saved guide ready in case the live demo has connection trouble.
- Decide which specific Project 1 steering change and Project 3 rule you personally agree with, so you can explain them without reading.
- Do not say that the controlled trials prove improved learning or a verified independent agent run.
