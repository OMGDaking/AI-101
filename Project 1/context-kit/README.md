# Context kit

This kit was assembled before the steering rounds. Each item gave the image model a specific constraint or visual target.

| Item | Job |
| --- | --- |
| [Palette/color palette.webp](Palette/color%20palette.webp) | Visual source for the teal, dark-wine, and magenta color family. |
| [Palette/palette.md](Palette/palette.md) | Defines the three exact production colors and their roles. |
| [Style-Note/Background Image 1.webp](Style-Note/Background%20Image%201.webp) | Reference for stacked architecture, cables, and a city-canyon perspective. |
| [Style-Note/Background image 2.webp](Style-Note/Background%20image%202.webp) | Reference for wet pavement, vertical density, and neon night contrast. |
| [Style-Note/Reference Image.webp](Style-Note/Reference%20Image.webp) | Reference for ribbed-glass distortion across the face and hair. |
| [Style-Note/style-note.md](Style-Note/style-note.md) | Turns the crowded reference material into spare poster constraints. |
| [intent/intent.md](intent/intent.md) | States the intended emotional effect: solitary, watchful, and slightly unreal. |

Every item was used: the photos established the city geometry and rain mood, the palette constrained color, the portrait reference supplied the optical treatment, and the notes directed composition and feeling.
