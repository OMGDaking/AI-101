# ADR-007 — Prepare a reviewable classroom copy
**Status** — AI-assisted retrospective, recorded November 19, 2026. Dakota review pending. Historical evidence comes from November 19 documentation session.
**Context** — The Project 4 packet contained a placeholder build. The personal app included a supplied commercial background recording with unverified redistribution permission.
**Decision** — Copy the saved app into build, retain runtime dependencies/licenses, omit the commercial MP3 and inactive intro assets, and disable the copied background controls.
**Consequence** — The instructor can run the classroom copy through localhost. The personal live site is not edited. Source provenance and remaining rights questions are explicit.
