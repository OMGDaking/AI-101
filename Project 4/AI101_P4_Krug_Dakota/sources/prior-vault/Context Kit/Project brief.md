# Project brief

Keyline helps a piano learner go from a recording to a practice session. The learner can import local audio, review a draft piano arrangement, watch the hands on the keyboard, and try the phrase at their own pace.

The main menu has four destinations: Lessons, Glove Locker, Import Music, and Settings. The practice screen centers on the playable keyboard and labeled hands. The intro is optional.

## What a useful session looks like

1. Find a lesson or import a recording.
2. Watch a whole phrase and see each finger press and release.
3. Slow or replay the phrase as needed.
4. In Try it, advance only after playing the expected notes.
5. Review the arrangement before relying on the sheet music or suggested fingering.
