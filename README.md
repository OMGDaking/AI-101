# Context kit

This folder was assembled before the steering rounds. Each item had a specific job in moving the model away from its default retro pin-up response.

| Item | Job |
| --- | --- |
| [Background image 2.webp](Background%20image%202.webp) | Reference photo for wet pavement, vertical city density, and magenta/blue night contrast. |
| [Background Image 1.webp](Background%20Image%201.webp) | Reference photo for stacked fire-escape geometry, cables, and the sensation of looking into a city canyon. |
| [color palette.webp](color%20palette.webp) | Palette reference; its teal, wine, and magenta family was reduced to the exact three colors in `palette.md`. |
| [Reference Image.webp](Reference%20Image.webp) | Material reference for vertical ribbed-glass distortion across the face and hair. |
| [palette.md](palette.md) | The exact three permitted production colors and their roles. |
| [style-note.md](style-note.md) | Constraints for turning a crowded neon reference into a spare, readable poster. |
| [intent.md](intent.md) | The emotional target used to assess each output. |

No item is unused: the city photos supplied environment and geometry, the restaurant image supplied the palette family, the portrait supplied the optical material, and the notes constrained color, composition, and mood.
